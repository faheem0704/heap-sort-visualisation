# Heap Sort Visualization

An interactive visualization of the Heap Sort algorithm with support for both Max Heap and Min Heap implementations. Built with Next.js and React.

## Features

- Interactive visualization of the heap sort algorithm
- Support for both Max Heap and Min Heap sorting
- Step-by-step visualization with play/pause functionality
- Tree visualization of the heap structure
- Custom input array support
- Real-time sorting state display

## Getting Started

### Prerequisites

- Node.js 14.0 or later
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/faheem0704/heap-sort-visualisation.git
```

2. Navigate to the project directory:
```bash
cd heap-sort-visualisation
```

3. Install dependencies:
```bash
npm install
```

4. Run the development server:
```bash
npm run dev
```

5. Open [http://localhost:3000](http://localhost:3000) in your browser to see the visualization.

## Usage

1. Enter numbers separated by commas in the input field
2. Choose between Max Heap or Min Heap sorting
3. Click "Visualize" to start
4. Use the control buttons to:
   - Step through the sorting process
   - Play the animation automatically
   - Reset the visualization
